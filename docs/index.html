Auto Close Confirmation Tabs

Automatically close login and confirmation tabs after the text you choose appears and a countdown finishes.

Download latest release View source

Useful for any confirmation page

Multiple rules

Add separate hostname and confirmation-text rules for different services.

Your countdown

Use the 3–20 second slider to choose how long to wait before closing.

Selected text

Pick an open HTTPS tab and let it fill in the hostname and selected confirmation text.

Local and limited

The extension processes page text locally and requests access only for configured hostnames.
